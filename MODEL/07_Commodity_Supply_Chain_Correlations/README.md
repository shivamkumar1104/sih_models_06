# Commodity Supply Chain & Freight Drivers

### 📊 Dataset Used:
- commodity_prices_supply_chain.csv (5,964 daily rows across 28 global commodities)

### 🌍 Key Macro Factors Tracked:
- **Energy & Bunker**: Brent Crude Oil, Natural Gas, Diesel (Direct impact on vessel operating voyage costs)
- **Steel & Metals**: Iron Ore 62% Fe, Coking Coal, Scrap Metal, Aluminum, Copper (Drives Capesize demand)
- **Thermal Energy**: Australian / Indonesian Thermal Coal (Drives Panamax & Supramax demand)
- **Agriculture**: Wheat, Corn, Soybeans (Drives Panamax seasonal harvest cycles)
